Logos de las compañías con las que trabajamos/comparamos (banda "Trabajamos con
las principales compañías" del informe PDF).

Cómo añadir un logo real:
1. Consigue el PNG oficial de la compañía (idealmente fondo transparente,
   al menos 400px de ancho).
2. Guárdalo en esta carpeta con el nombre EXACTO indicado abajo (todo en
   minúsculas, sin espacios).
3. Vuelve a compilar (`npm run build`). El informe lo detecta solo: si el
   archivo existe se usa el logo, si no existe se dibuja una pastilla con
   el nombre de la compañía como respaldo.

Nombres de archivo esperados:
  energia:   endesa.png   iberdrola.png   naturgy.png
  telefonia: movistar.png vodafone.png    orange.png
  alarmas:   securitas.png prosegur.png

Nota: no se han incluido logos reales en este proyecto porque son marcas
registradas de terceros; súbelos vosotros mismos con los originales
oficiales de cada compañía.
